# موقع العيديات الذكية - نظام توزيع العيديات مع الأسئلة الدينية

نظام تفاعلي وذكي لتوزيع العيديات على الأطفال مع أسئلة دينية شيقة حول العيد الكبير والحج.

## المميزات الرئيسية

🎯 **إنشاء خطط مخصصة**: حدد المبلغ الإجمالي والفئات الورقية وعدد الأطفال بسهولة
❓ **أسئلة دينية شيقة**: 100+ سؤال عن العيد الكبير والحج بمستويات صعوبة مختلفة
🐑 **واجهة تفاعلية للأطفال**: اضغط على الخروف واحصل على العيدية بعد الإجابة على سؤال
📊 **إحصائيات فورية**: تابع عدد الأطفال والمبلغ الموزع والمتبقي
🔗 **مشاركة سهلة**: شارك الخطط مع الآخرين أو استخدم كود الجلسة لبدء جلسة جديدة

## التكنولوجيا المستخدمة

- **Frontend**: Next.js 16 + React 19 + TypeScript
- **Styling**: Tailwind CSS 4 + shadcn/ui
- **Database**: Neon PostgreSQL
- **Authentication**: Simple session-based (يمكن تحسينها)
- **API**: Next.js Route Handlers

## البنية البيانية

### الجداول الرئيسية

1. **users**: بيانات المستخدمين
2. **plans**: خطط التوزيع (الاسم، المبلغ، عدد الأطفال، إلخ)
3. **denominations**: الفئات الورقية لكل خطة
4. **questions**: البنك الأساسي للأسئلة الدينية
5. **sessions**: جلسات التوزيع (كود الجلسة، الحالة، الإحصائيات)
6. **rewards**: العيديات الموزعة والنتائج
7. **plan_questions**: تحديد الأسئلة المستخدمة في كل خطة

## الصفحات الرئيسية

### 1. الصفحة الرئيسية (`/`)
- عرض عام عن الموقع
- زر الدخول لمنطقة المدير
- شرح كيفية الاستخدام

### 2. منطقة المدير (`/admin`)
- **تبويب "إنشاء خطة"**: نموذج لإنشاء خطة جديدة
  - إدخال اسم الخطة
  - تحديد المبلغ الإجمالي
  - اختيار عدد الأطفال
  - اختيار الفئات الورقية
  - اختيار مشاركة الخطة علناً
  
- **تبويب "الخطط المشاركة"**: عرض الخطط العامة
  - بطاقات تفصيلية لكل خطة
  - زر لبدء جلسة جديدة
  - نسخ رابط الجلسة
  
- **تبويب "الجلسات"**: إدارة الجلسات النشطة
  - عرض الإحصائيات الحية
  - نسخ رابط الجلسة
  - عرض الجلسة

### 3. صفحة اللعبة (`/play?sessionCode=...`)
- واجهة تفاعلية للأطفال
- لوحة لعبة مع خروف متحرك
- نموذج السؤال الديني
- عرض العيدية عند الإجابة الصحيحة
- إحصائيات الجلسة الحية

## كيفية الاستخدام

### للآباء/المدير:

1. اذهب إلى `/admin`
2. املأ بيانات الخطة:
   - اسم الخطة (مثلاً: عيديات رمضان 2024)
   - المبلغ الإجمالي (مثلاً: 1000 جنيه)
   - عدد الأطفال المتوقع
   - اختر الفئات الورقية (5, 10, 20, 50, 100, 200 جنيه)
3. انقر "إنشاء الخطة"
4. من تبويب "الخطط المشاركة" أو داخل الخطة، انقر "ابدأ جلسة جديدة"
5. سيحصل على كود الجلسة ورابط يمكن مشاركته مع الأطفال

### للأطفال:

1. ادخل الرابط المشارك من الآب (مثلاً: https://yoursite.com/play?sessionCode=ABC123)
2. اضغط على الخروف 🐑
3. سيظهر مبلغ عشوائي من الفئات المحددة
4. أجب على السؤال الديني الذي يظهر
5. إذا أجبت صح → احصل على العيدية! 🎉
6. إذا أجبت خطأ → سيظهر سؤال أسهل برقم أقل (من فئة أقل)
7. استمر في المحاولة حتى تحصل على عيدية أو تصل إلى أقل فئة

## API Routes

### `/api/plans`
- `GET`: جلب الخطط (عامة أو للمستخدم)
- `POST`: إنشاء خطة جديدة

### `/api/questions`
- `GET`: جلب الأسئلة (حسب مستوى الصعوبة)
- `POST`: إضافة سؤال جديد

### `/api/sessions`
- `GET`: جلب جلسات (حسب plan_id أو session_code)
- `POST`: إنشاء جلسة جديدة

### `/api/rewards`
- `GET`: جلب العيديات الموزعة في جلسة معينة
- `POST`: تسجيل عيدية جديدة
